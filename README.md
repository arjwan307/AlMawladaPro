# AlMawladaPro | المولدة برو

نظام مستقل لإدارة المولدات الأهلية واشتراكات المشتركين.

## حالة المشروع
مرحلة التأسيس. المتطلبات التفصيلية ونموذج الواجهات قيد المطابقة قبل تنفيذ العمليات المالية.

## الوحدات المقترحة
- إدارة المولدات والمشتركين
- الاشتراكات والتعرفة والأمبيرات
- الفواتير والقبض والديون
- المصروفات والتقارير
- المستخدمون والصلاحيات والنسخ الاحتياطي

> لا توجد بيانات إنتاج أو وظائف محاسبية مكتملة بعد.

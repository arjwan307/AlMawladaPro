# AlMawladaPro — المولدة برو

نسخة أولية قابلة للتشغيل لنظام إدارة اشتراكات المولدة الأهلية، بواجهة عربية RTL مستوحاة من النموذج المرفق.

## التشغيل
1. ثبّت Node.js 22.13 أو أحدث (يفضّل 24).
2. افتح مجلد المشروع وشغّل `npm start`.
3. افتح `http://localhost:3000`.

لا يحتاج تثبيت حزم npm خارجية. تستخدم النسخة SQLite المدمجة في Node.js.

## الوظائف
- إضافة مشترك مع عدد الأمبيرات وبيانات الاتصال.
- ضبط سعر الأمبير الشهري.
- إنشاء فواتير شهرية دون تكرارها.
- تسجيل دفعات جزئية أو كاملة مع منع دفع مبلغ أكبر من المتبقي.
- مصروفات الوقود والصيانة والأجور.
- لوحة تحكم وفلاتر وإجماليات شهرية.

## ملاحظات قبل الاستخدام التجاري
- نسخة تطوير أولية، **ليست جاهزة للنشر على الإنترنت**: لا توجد مصادقة أو صلاحيات بعد.
- لا تحتوي على بيانات مشتركين تجريبية، حمايةً من خلطها بالبيانات الحقيقية.
- يتم حفظ البيانات في `data/generator.sqlite`؛ انسخ الملف احتياطياً بعد إيقاف الخادم.
- العمل من عدة أجهزة عبر LAN والنظام المالي المتقدم والطباعة وإدارة الديون المتراكمة بين الشهور مراحل لاحقة.
- قيمة الاشتراك تُثبت عند إنشاء الفاتورة، ولا تتغير بتغيير السعر لاحقاً.
